      Algorithm Feature Space Pipeline

      Inputs are vectorized using **TF-IDF (Term Frequency-Inverse Document Frequency)** matching words and sub-sequences of words (N-grams ranges 1 to 2). The tokenizer filters English stopwords and standardizes capitalization, maps text inputs to a sparse high-dimensional vector space, and predicts category vectors:

      Algorithm Feature Selection Model Weights Use Case Target
      Logistic Regression Sparse TF-IDF Vectors (L2 Normalization) Maximum Likelihood Estimation Coefficients Balanced text classifications, general multi-class scam detection.
      Naive Bayes (Multinomial) Word count relative frequencies (Laplace smoothed) Prior probability logs + feature likelihood logs Fast keyword-frequency-focused checks, high-volume spam.
      Random Forest Decision tree sub-selection matrices Entropy split thresholds, weighted voting Identifies complex combinations of multi-word flags.
